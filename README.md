# Nicaexport-Analisis-comercio
Caso de Estudio: Gestión y Análisis de Operaciones de Comercio Internacional
Nombre del proyecto:Análisis Operativo y Estratégico de Comercio Internacional
Empresa:Nica Export Trading, S.A.
Objetivo:Analizar las operaciones de exportación del primer semestre de 2026 para determinar los mercados principales, productos de mayor demanda y la rentabilidad por operación.
Integrante:kelcy valdivia martinez 
Herramientas Utilizadas: Microsoft Excel con las Funciones BUSCARV, SI, SI anidado, CONTAR.SI, SUMAR.SI, SUMAR.SI.CONJUNTO, Tablas dinámicas y Gráficos, Microsoft PowerPoint en la Presentación gerencial de 8 diapositivas y GitHub en el Control de versiones, Issues y trabajo individual.
Resumen de Resultados: se analizaron operaciones evaluadas hacia EE.UU., México, Costa Rica, Guatemala, El Salvador y España encontrándose como mercado Principal en Valor FOB Estados Unidos, por otro lado la mayoría de operaciones mantienen un nivel de rentabilidad Alta (≥ 30%).
 Conclusiones: 1. Norteamérica representa el volumen de ingresos FOB más alto para la empresa. 2. El café especial es el producto de mayor impacto comercial y margen de ganancia. 3. Existen 15 operaciones en estado Pendiente que deben ser liberadas para no afectar el flujo de caja.
 Recomendaciones 1. Promoción enfocada:Incrementar la comercialización de café especial en EE.UU. por su alta rentabilidad. 2. Gestión de pendientes: Crear un plan de seguimiento logístico para entregar las 15 operaciones pendiente 3. Estrategia en Europa:Optimizar rutas de envío hacia España para maximizar la utilidad neta.
